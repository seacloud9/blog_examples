# Blog Examples

Welcome! This repository is home to the articles, experiments, and working examples we share on [Medium](https://medium.com/@seacloud9).

Here you can go beyond the finished stories: explore the source material, view supporting screenshots, and try the small demonstrations that accompany each post. The collection focuses on practical AI, local-first tools, thoughtful automation, and the lessons learned while turning ideas into working systems.

## Articles and examples

### [From Zero to One: I Turned a Local Qwen Agent Into a Human-Gated Publishing System](./dashboad-open-claw1/)

Follow the journey from a locally running language model to a controlled publishing workflow in which every public action remains subject to human review. The entry includes the full article, screenshots, and a dependency-free Node.js demonstration of an exact-payload approval queue.

### [From One Queue to a Local Command Center](./dashboad-open-claw2/)

Part 2 explores how specialist agents, review queues, schedules, and honest receipts fit together. Fictional personas, a clearly labeled dashboard demo, and a local routing example keep the walkthrough safe to explore.

### [I Gave My Local LLM a Job Description. It Still Needed a Manager.](./openclaw-agent-creation/)

Go beneath the dashboard to design an OpenClaw agent using a local LLM. This companion explains roles, workspace instructions, output contracts, and the checks that turn a draft into reviewable work. Includes fictional workspace templates and a runnable validator.

## A note about the examples

The projects in this repository are educational companions to the articles. Check each entry's README for its requirements, setup instructions, and scope before running it. Examples are intentionally kept focused and may omit production concerns that are not relevant to the topic being demonstrated.
